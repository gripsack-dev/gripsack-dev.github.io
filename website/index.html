start with one useful change

A file-only workspace needs no package build or Docker service. Save this as gripsack.ts in its own repository:

gripsack.ts
import {
  defineWorkspace, file, literalText, managedBlock, profile, workspace,
} from "@gripsack/core";

const dotfiles = profile("dotfiles", {
  files: [file({
    content: literalText("export EDITOR=vi\n"),
    destination: managedBlock("~/.profile", "gripsack-editor"),
  })],
});

export default defineWorkspace(() => workspace({ outputs: [dotfiles] }));

After installing grip, review the captured source and policy when prompted:

grip check
grip plan dotfiles
grip apply dotfiles

Review the plan before applying. grip generations lists retained states; grip rollback restores a previous managed generation. Keep independent backups of irreplaceable files. Understand ownership and recovery →
