Gripsack / documentation

Source builder retired

The BuildKit source-recipe backend and OCI image export were retired in 0.51. This page exists so old links still land somewhere useful.

  • To run an existing, digest-pinned image, use Docker Engine services. Gripsack does not build images.
  • To get a tool from a release archive, Conda or a Pixi lock, use packages and environments.
  • To move retained package content to another machine or a registry, use sharing; its OCI transport is not a runnable container image.

Native packages, dotfiles and tasks do not require Docker.
