# What's new

Gripsack brings user-space packages, native environments, profiles, manual tasks, BuildKit source builds and OCI image exports into one typed workspace. Start with the [workspace guide](workspaces.md), then explore [packages](packages.md), [profiles](adopting.md) or [builds and images](builds.md).

## Release history

The canonical [changelog](https://github.com/gripsack-dev/gripsack/blob/{release_source}/CHANGELOG.md) lives with the core source. [Release notes and downloads](https://github.com/gripsack-dev/gripsack/releases) carry version-specific installation instructions, checksums and verification records.

This site documents the selected core source; it does not mirror historical API guides or release evidence into the product tutorials. See [installation](install.md) for current prerequisites and [safety](safety.md) for operational boundaries.
